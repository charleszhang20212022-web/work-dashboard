# 업무 종합 대시보드 (Work Dashboard)

순수 HTML · CSS · JavaScript 로 제작한 **업무 종합 관리 대시보드**입니다.
외부 라이브러리나 인터넷 연결 없이 동작하며, 모든 차트는 SVG 로 직접 렌더링됩니다.

> 가상의 회사 **「오로라 테크놀로지」** 의 운영 데이터를 예시로 구성한 범용 템플릿입니다.

---

## 화면 구성

| 페이지 | 파일 | 내용 |
|--------|------|------|
| 종합 개요 | `index.html` | 핵심 지표(KPI), 매출 추이, 업무 진행 상태, 부서별 달성률, 최근 활동 |
| 업무 목록 | `tasks.html` | 업무 통계, 상태 필터 · 검색, 담당자별 진행 현황 표 |
| 프로젝트 | `projects.html` | 프로젝트 통계, 간트형 타임라인, 프로젝트 상세 카드 |
| 보고서 | `reports.html` | 분기별 실적, 매출 채널 비중, 팀별 성과, 핵심 인사이트 |

## 주요 기능

- **반응형 레이아웃** — 데스크톱 · 태블릿 · 모바일 화면 대응
- **인터랙티브 차트** — SVG 라인 / 도넛 / 막대 차트, 마우스 오버 툴팁
- **진입 애니메이션** — 숫자 카운트업, 차트 드로잉 효과
- **필터 & 검색** — 업무 목록의 상태 필터와 실시간 검색
- **기간 토글** — 매출 추이 차트의 12개월 / 7일 전환

## 파일 구조

```
work-dashboard/
├── index.html          종합 개요 페이지
├── tasks.html          업무 목록 페이지
├── projects.html       프로젝트 페이지
├── reports.html        보고서 페이지
├── css/
│   └── style.css       공통 스타일시트
├── js/
│   ├── data.js         샘플 데이터
│   ├── components.js   공통 UI · 차트 렌더링 엔진
│   └── app.js          페이지별 초기화 로직
└── README.md
```

## 실행 방법

별도의 설치 과정 없이 `index.html` 파일을 웹 브라우저로 열면 됩니다.

```
work-dashboard/index.html  →  더블 클릭 또는 브라우저로 열기
```

좌측 사이드바 메뉴를 통해 4개 페이지를 이동할 수 있습니다.

## 사용 기술

- HTML5 / CSS3 (Flexbox · Grid · CSS 변수)
- Vanilla JavaScript (ES5 문법 기준, 빌드 도구 불필요)
- SVG 기반 자체 제작 차트 (외부 차트 라이브러리 미사용)
